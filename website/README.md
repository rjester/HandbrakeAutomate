# AutomateHandbrake — Companion Website

This folder contains a minimal React + Vite + TypeScript scaffold for a static companion
website to document the AutomateHandbrake PowerShell scripts.

Quick start:

1. Install dependencies:

```bash
cd website
npm install
```

2. Run development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

4. Deploy to GitHub Pages (uses `gh-pages`):

```bash
npm run deploy
```

Customize content in `src/pages/Home.tsx` and styles in `src/styles.css`.
